# AgriConnect 🌿

AgriConnect is a smart agricultural resource management platform that connects farmers with agricultural workers, machine owners, worker groups, and contract service providers.

## Features

* User Signup and Login
* Worker Registration
* Farmer Job Posting
* Machine Registration
* Smart Matching
* Booking Module
* Marketplace

## Tech Stack

### Frontend

* HTML
* CSS
* JavaScript
* REACT.JS

### Backend

* Java
* Spring Boot
* REST APIs

### Database

* PostgreSQL

## Problem Statement

Farmers often struggle to find labor, machines, and agricultural services at the right time. AgriConnect solves this problem by providing a centralized digital platform for resource discovery and booking.
